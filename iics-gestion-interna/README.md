# 🚀 SGR-ACS: Sistema de Gestión de Revista
### *Executive Drive Edition*

![Banner](https://github.com/Jhanpiere-cmd/SGR-ACS/raw/main/public/banner.png)

## 💎 Visión General
**SGR-ACS** es una plataforma de gestión integral diseñada para el Equipo de Comunicación y Marketing de la revista académica "Alternativas en Ciencias Sociales". Este sistema redefine la operatividad institucional mediante una interfaz de **alto rendimiento, estética premium y automatización inteligente**.

---

## ✨ Características de Élite

### 👔 Gestión Ejecutiva y Estratégica
*   **Dashboard Sistémico**: Control Total en tiempo real con métricas de KPI avanzadas.
*   **Workflow Dinámico**: Asignación de tareas con prioridades heredadas y roles dinámicos.
*   **Centro de Evidencia**: Gestión centralizada de archivos y feedback para auditorías rápidas.

### 📊 Inteligencia de Marketing (Growth)
*   **Omnichannel Sync**: Integración nativa para monitorear impacto en Meta (FB/IG) y YouTube.
*   **Reportes de Dirección**: Generación automática de documentos oficiales listos para firma.

### 📜 Automatización de Certificados
*   **Motor PDF Dinámico**: Emisión masiva de certificados con validación de autenticidad QR.
*   **Plantillas Premium**: Diseños institucionales que cumplen con los más altos estándares académicos.

### 💰 Finanzas y Auditoría
*   **Ledger Inteligente**: Control de ingresos y egresos con categorización asistida por IA (Gemini).
*   **Trazabilidad Total**: Cada movimiento financiero está vinculado a una actividad y responsable.

---

## 🛠️ Stack Tecnológico de Vanguardia
*   **Core**: [React 19](https://react.dev/) + [Vite 6](https://vitejs.dev/)
*   **Base de Datos & Auth**: [Supabase](https://supabase.com/) (PostgreSQL)
*   **IA Engine**: [Google Gemini Pro](https://ai.google.dev/)
*   **Estética**: Vanilla CSS con variables de diseño *Executive Blue*
*   **Documentos**: jsPDF & docx-templates

---

## 🚀 Instalación Rápida

1.  **Clonar el universo de trabajo:**
    ```bash
    git clone https://github.com/Jhanpiere-cmd/SGR-ACS.git
    cd SGR-ACS
    ```

2.  **Preparar el entorno:**
    ```bash
    npm install
    ```

3.  **Lanzar la central de operaciones:**
    ```bash
    npm run dev
    ```

---

## 🔐 Seguridad y Roles
El sistema opera bajo una arquitectura **Zero Trust** utilizando Supabase RLS. Solo personal autorizado tiene acceso a los módulos financieros y de auditoría.
